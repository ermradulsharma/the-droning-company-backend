# Contributing to The Droning Company - Backend

Thank you for your interest in contributing to The Droning Company backend! We welcome contributions that help improve the platform.

## Code of Conduct

Please be respectful and professional in all interactions.

## How to Contribute

1.  **Report Bugs:** Use the GitHub Issue Tracker to report bugs. Provide as much detail as possible, including steps to reproduce.
2.  **Suggest Features:** We're open to new ideas! Open an issue to discuss your feature request.
3.  **Pull Requests:**
    - Fork the repository and create your branch from `main`.
    - Ensure your code follows the PSR-12 coding standard.
    - Write or update tests for your changes.
    - Update documentation if necessary.
    - Open a pull request with a clear description of the changes.

## Development Setup

Follow the instructions in the [README.md](README.md) to set up your local development environment.

## Coding Standards

We follow [PSR-12](https://www.php-fig.org/psr/psr-12/) for PHP code formatting. You can check your code style using:

```bash
./vendor/bin/phpcs --standard=PSR12 app/
```

## Branching Model

We use a feature-branching model. Please name your branches descriptively:

- `feature/description-of-feature`
- `bugfix/description-of-fix`
- `hotfix/urgent-fix`
